contract surface

What the runner owns

Deterministic DAG execution

Consumes a precompiled order and executes nodes for exactly one run.

Executor registry

Built-in control/JSON primitives stay small; domain behavior is host-pluggable.

Branch propagation

Inactive output ports suppress downstream execution; nodes with only inactive inputs are skipped.

Retries + cancellation

Attempts and abort signals are runtime concerns, surfaced through structured results and events.

explicit non-goals

What belongs elsewhere

  • workflow authoring and compilation → workflow-editor
  • registration, versions, triggers, cron/webhooks → workflow-engine
  • persistent queues and distributed workers → later orchestration infrastructure
